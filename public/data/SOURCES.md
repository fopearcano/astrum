# Data sources

The JSON files in this folder are generated by `scripts/build-data.mjs` from the
open datasets below. Each derived file keeps its source's licence.

| File | Source | Licence |
| --- | --- | --- |
| `stars.json`, `hr.json`, `nearby.json` | [HYG Database v4.1](https://codeberg.org/astronexus/hyg) by David Nash (Hipparcos, Yale Bright Star and Gliese catalogues) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| `constellations.json`, `milkyway.json`, `messier.json` | [d3-celestial](https://github.com/ofrohn/d3-celestial) data by Olaf Frohn | BSD 3-Clause |
| `exoplanets.json`, planet-host flags in `nearby.json` | [Open Exoplanet Catalogue](https://github.com/OpenExoplanetCatalogue/oec_tables) by Hanno Rein and contributors | MIT |

`stars.json`, `hr.json` and `nearby.json` are adaptations of HYG and are
distributed under CC BY-SA 4.0. Changes: filtered by magnitude or distance,
rounded, Bayer designations converted to Greek letters, and positions
converted to galactic coordinates (`nearby.json`).
